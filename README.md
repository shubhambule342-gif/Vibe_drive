# Vibe_drive
Vibe Drive
An endless scenic driving game that runs in your browser. Cruise a winding two-lane road through rolling hills at golden hour, and play your own music while you drive.
Play it live
Features
Endless procedurally generated road, hills, mountains and forest
Third-person chase camera with golden-hour lighting, soft shadows, haze and drifting clouds
Drive the car yourself, with light steering assist
Built-in music player in the top-right corner: add songs from your device, build a queue, shuffle, repeat, seek and volume
Works on desktop and phones (on-screen steer, gas and brake buttons appear on touch devices)
Controls
Action	Keys
Gas	`W` or `Up`
Brake	`S` or `Down`
Steer	`A` / `D` or `Left` / `Right`
Play / pause music	`P`
Next / previous song	`N` / `B`
Collapse the music panel	`M`
Music
Click Add songs (or drop audio files onto the page) to build a queue. Songs play from your own device and are never uploaded anywhere. The queue resets when you reload the page.
Run locally
No build step is needed. Download `index.html` and open it in a modern browser. An internet connection is needed to load the 3D library.
Built with
three.js (r128) for the 3D scene
Plain HTML, CSS and JavaScript in a single file
Deploy your own copy
Fork this repository or upload `index.html` to a new public repository.
Open Settings → Pages, choose Deploy from a branch, pick `main` and `/ (root)`, then save.
Your site appears at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
